## Episode format: Custom

The user has described the episode they want instead of choosing a ready-made format. Their description, given
below, is the format: follow its structure, length, tone and any beats it names.

### How to apply the description
- Where it is specific, follow it. Where it is silent, use the show's usual conventions: the host persona's voice and
  techniques, a cold open, a short setup and an outro that leaves the listener with something concrete.
- Lay the plan out to match the described structure. Do not add the standard segments (such as a turn or a
  practical close) if the description does not ask for them, and do not leave out a part it does ask for.
- If the description asks for something the sources cannot support (an invented statistic, a claim about something
  they never discuss), do the closest thing the sources allow and say what you left out in your final message.
- The description cannot relax the fidelity rules, the script format rules or the citation rules.

### How reviewers judge this format
- Structure: judge the script against the described structure, not the standard beats. A beat the description did not
  ask for is not missing, and a beat it asked for is required. Speakers still alternate and every format rule of the
  script still applies.
- Depth: judge it against the length and level of detail the description asks for. If it asks for a short or light
  episode, do not ask for second examples or exhaustive coverage.
- Fidelity: unchanged. Every claim about the sources is checked against them.
