# AI Influencer Agency

A multi-agent system that designs, launches, and runs the content operation for one or more AI-generated influencer personas — character, personality, backstory, and voice, kept consistent across every post — coordinated through a single conversational orchestrator.

Built on [LangGraph](https://github.com/langchain-ai/langgraph) and [LangChain](https://github.com/langchain-ai/langchain), with models served through [OpenRouter](https://openrouter.ai/) and traced with [Opik](https://www.comet.com/site/products/opik/).

## What it does

You talk to one **Orchestrator** agent through a terminal chat interface. It doesn't do any of the actual work itself — it routes each request to the right department and relays the result back:

- **🎭 Persona & Identity** — creates a brand-new influencer from scratch: character design, personality, backstory, and sample images, generated by three specialist agents and finalized only after a human review checkpoint.
- **🎬 Content Production** — plans a content calendar and produces individual posts (caption + image/video) for an influencer that already exists, then publishes or schedules them via [Buffer](https://buffer.com/).
- **💬 Engagement & Community** — surfaces how an influencer's content is performing on Instagram/Threads (recent media, engagement metrics). Replying to audience comments happens automatically through a separate webhook flow, not through the orchestrator.

A fourth department, **Monetization**, is planned but not wired up yet.

Every specialist agent keeps a learning loop: an auditor reviews each run's traces and saves reusable "skills" back to the relevant agent, so repeated mistakes get corrected over time rather than repeated.

## Architecture

```
                    ┌────────────────┐
      you  ───────► │  Orchestrator  │
                    └───────┬────────┘
             ┌──────────────┼──────────────────┐
             ▼               ▼                  ▼
   Persona & Identity   Content Production   Engagement & Community
   ├─ Character Design   ├─ Content Manager   └─ Engagement Specialist
   ├─ Personality        ├─ Content Strategist    (insights only —
   ├─ Backstory          └─ SM Content Writer      replies run via webhook)
   └─ (human review)          │
                              └─ published via Buffer
```

Each agent runs as its own LangGraph graph with its own checkpointed conversation thread (SQLite), so state — including a paused persona review awaiting your decision — survives across turns and process restarts. A shared Postgres-backed store holds cross-agent memory (persona details, learned skills). Every agent call is traced through Opik, and token usage is logged separately to `logs/token_usage.jsonl` for later analysis.

## Requirements

- Python ≥ 3.12
- Docker (for the Postgres-backed shared memory store)
- API keys: OpenRouter, Opik, Buffer, Mistral (moderation), and Meta (for the Instagram/Threads webhook)

## Setup

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows
pip install -e ".[dev]"
```

Create a `.env` file in the project root with:

```
OPENROUTER_API_KEY=...
OPIK_API_KEY=...
BUFFER_API_KEY=...
MISTRAL_API_KEY=...
META_APP_SECRET=...
META_WEBHOOK_VERIFY_TOKEN=...

POSTGRES_URI=postgresql://<user>:<password>@localhost:5432/<db>?sslmode=disable
POSTGRES_USER=postgres
POSTGRES_PASSWORD=...
POSTGRES_DB=ai_influencer

# One pair per influencer, used to route incoming webhook events:
<INFLUENCER_SLUG>_INSTAGRAM_USER_ID=...
<INFLUENCER_SLUG>_THREADS_USER_ID=...
```

Start the shared Postgres store:

```bash
docker compose up -d
```

## Running it

```bash
influencer_agency          # or: python -m src.cli.main
```

This opens a Textual-based chat TUI. Type naturally (e.g. *"create a new fitness influencer"*, *"plan next week's content for Zoe"*); `/` opens a command menu:

| Command | Does |
|---|---|
| `/sessions` | Browse, switch to, or start a new named conversation |
| `/new` | Start a fresh conversation in the current session |
| `/influencers` | Pick which influencer this session manages |
| `/quit` | Exit |

`influencer_agency sessions` and `influencer_agency influencer` are also available outside the TUI, for listing sessions and setting the default influencer for new ones.

### Automatic daily posting

Rather than instructing the orchestrator by hand every day, ask it in chat (e.g. *"schedule daily posting for 2:30pm"*) — it manages a Windows Scheduled Task that runs `src/cli/scheduled_run.py` at that time, which drives the orchestrator through a full content-production turn unattended. Say *"what's the current posting schedule?"* or *"turn off automatic posting"* to check or remove it. This requires `docker compose up -d` (Postgres) to already be running.

### Comment/mention replies

`src/agents/engagement_community/webhook.py` is a FastAPI app that receives Instagram/Threads webhook events from Meta and hands each one to the engagement specialist to answer. Run it with:

```bash
uvicorn src.agents.engagement_community.webhook:app
```

```
│   ├── persona_identity/     # Character/personality/backstory specialists + workflow
│   ├── content_production/   # Manager + content strategist + SM content writer
│   └── engagement_community/ # Insights agent + Meta webhook receiver

```
